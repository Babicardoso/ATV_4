🛒 Desafio: Cadastro de Produtos com PHP e MySQL

Projeto desenvolvido para solucionar o desafio prático proposto em 10a_desafio2.md. A aplicação consiste em um formulário web interativo para cadastro de produtos com validação de dados no lado do servidor em PHP e persistência no banco de dados MySQL.

📌 Funcionalidades

Formulário de Entrada: Interface web simples contendo os campos Nome do Produto e Preço.

Validação Server-Side (PHP):

Garantia de que o campo Nome do Produto não esteja vazio.

Validação do campo Preço para garantir que seja numérico e estritamente positivo (> 0).

Persistência em Banco de Dados: Inserção segura dos dados válidos no banco exercicio.

Tratamento de Mensagens:

Exibição de confirmação: "Produto cadastrado com sucesso!".

Mensagens amigáveis em caso de erro, como "Erro: O preço deve ser um número positivo.".

🛠️️ Tecnologias Utilizadas

PHP — Lógica do servidor e validação dos dados.

MySQL / MariaDB — Armazenamento relacional de dados.

HTML5 — Estruturação do formulário web.
